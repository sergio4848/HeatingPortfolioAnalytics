# Portotherm design system

The existing provisional name, portfolio-column symbol, navy #142B3D and teal #006D77 remain. English is the default. Existing prepared locale files remain; Latvian copy still needs review.

`apps/web/src/tokens.css` centralizes paper/ink/accent/line/state colors, Inter UI and tabular data typography, spacing, radius and motion. Existing workspace semantic aliases are retained. New feature styles use these tokens; legacy theme styles remain for compatibility.

The marketing surface uses large left-aligned type, an asymmetric live engine preview, clear section rules and four genuine product captures. The working application uses compact page headers, visible periods/units, numeric alignment, separate quality/status labels, chart/table alternatives and controlled table overflow. Additional Buildings, Findings, Reports and Assistant routes are available through Workspace views; primary mobile navigation stays compact.

Every external AI request has a data disclosure and unchecked consent control. Disabled/unconfigured AI is explained in text. Observations and hypotheses are separate; metric values are rendered from the backend evidence package. Source dialogs show authorized records; local document management works without an API key. Task draft approval is separate from generation.

Controls retain visible focus, keyboard operation and readable empty/error states. Touch controls target 44px. Responsive evidence is in reports/ui-review, including tablet metric-grid correction. Automated checks are not an independent accessibility certification.
