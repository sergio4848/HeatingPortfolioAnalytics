## Logo directions
Selected direction 1: portfolio columns and an investigation signal (symbol-light.svg). Original geometry, no flame or copied icon. Direction 2 building bars/baseline is architectural but less analytical. Direction 3 roof/signal bars loses definition at small sizes. Both alternatives remain editable SVGs.

Minimum symbol 16 px, prefer 24/32 px. Minimum wordmark 128 px wide. Clear space one column width around symbol, half-symbol around wordmark. Preserve proportions/colors. Do not stretch, rotate, add glow, recolor warning amber, overlay busy photos or imply official certification. Exports include light/dark/mono SVG and transparent PNG, favicon and 192/512 application icons. Preview sheet includes 16/24/32 px checks and misuse examples.

25 words: Portotherm helps apartment portfolio managers prioritize buildings for investigation using existing monthly heat data, transparent weather comparisons, quality checks, review tasks, and documented follow-up evidence.

80 words: Portotherm is a proposed software tool for professional apartment management companies. It uses existing monthly heat consumption records to identify buildings worth investigating, checks data quality, and compares consumption with each building’s own history and weather reference. Managers can review the reasons, assign follow-up tasks, record interventions, and export evidence with clear limitations. The local demonstration uses synthetic data. A proposed six-week pilot would test usefulness with authorized records and expert feedback before making commercial or energy-saving claims in practice.

Use investigation priority, weather reference, observed deviation, data review and scenario estimate. Avoid guaranteed saving, fault certainty, real-time and endorsement claims. Latvian copy requires a human reviewer.
